            Feed Cycle Tuning
            

                
                

                

                    How long to wait for Sensor 1 to first go BLOCKED (card reaches the feed sensor) before the attempt is considered a failure.
                


                
                

                

                    After Sensor 1 is triggered, Motor 2 will continue feeding for this many seconds before stopping and reversing.
                


                
                

                

                    How long to wait for Sensor 1 to clear while Motors 1 & 2 reverse before the attempt is considered a failure.
                


                
                

                

                    Once Sensor 1 clears, Motors 2 & 3 run forward together to push the card into Sensor 2. How long to wait for Sensor 2 to trigger before the attempt is considered a failure.
                


                
                

                

                    After Sensor 2 is triggered, Motors 2 & 3 will continue running for this many seconds before stopping (useful for pushing the card past a physical obstruction; set to 0 to stop immediately).
                


                
                

                

                    Number of attempts per feed cycle round. A single feed cycle runs up to two rounds of this many attempts each (a recovery sequence runs between rounds), so the total attempts before giving up is double this value.
                


                
                

                    Logs each phase's start/stop, duration, and live Sensor 1 / Sensor 2 values to a file for diagnosing jams and timing issues. Adds a small amount of disk I/O per feed, so leave off unless actively debugging.
